# Culinary Exchange - Платформа для обмена кулинарными рецептами

Culinary Exchange - это веб-приложение для любителей кулинарии, где пользователи могут делиться своими рецептами, находить вдохновение в рецептах других, сохранять понравившиеся рецепты и участвовать в кулинарном сообществе.

## Основные возможности
### Управление пользователями
Регистрация с указанием кулинарных предпочтений

Аутентификация с использованием безопасного хеширования паролей

Профиль пользователя с аватаром, информацией о предпочтениях и рейтингом

Редактирование профиля и кулинарных предпочтений

### Управление рецептами
Создание рецептов с детальным описанием, ингредиентами и шагами приготовления

Загрузка изображений для рецептов (обложка и дополнительные фото)

Редактирование и удаление собственных рецептов

Просмотр рецептов с оценками и комментариями

### Избранное и рейтинги
Добавление рецептов в избранное

Система оценок от 1 до 5 звезд

Комментирование рецептов

Сортировка рецептов по категориям

### Поиск и навигация
Поиск рецептов по названию и ингредиентам

Фильтрация по категориям кухонь

Просмотр популярных рецептов

### Административные функции
Управление пользователями (назначение/лишение прав администратора)

Управление категориями рецептов

Просмотр статистики приложения

## Технологический стек
### Backend
Java - основной язык программирования

Servlets/JSP - обработка HTTP-запросов и представление

PostgreSQL - система управления базами данных

Maven - управление зависимостями и сборка проекта

### Frontend
HTML5/CSS3 - разметка и стилизация

JavaScript - интерактивность

JSTL - теги для JSP

Bootstrap - адаптивный дизайн (частично)

### Безопасность
JBCrypt - хеширование паролей

Сессии для управления аутентификацией

Фильтры для контроля доступа к защищенным страницам

### Дополнительные библиотеки
Lombok - уменьшение шаблонного кода

Apache Commons FileUpload - обработка загрузки файлов

## Структура проекта
```text
culinaryExchange/
├── src/main/java/org/example/
│   ├── controllers/     # Сервлеты и обработчики запросов
│   ├── dao/            # Data Access Objects (DAO)
│   ├── entity/         # Сущности базы данных
│   ├── filter/         # Фильтры (аутентификация, права доступа)
│   ├── service/        # Бизнес-логика
│   └── util/           # Вспомогательные классы
├── src/main/webapp/
│   ├── WEB-INF/views/  # JSP-страницы
│   ├── styles/         # CSS-стили
│   └── uploads/        # Загруженные изображения
└── pom.xml            # Конфигурация Maven
```

## База данных
Приложение использует PostgreSQL со следующей основной структурой:

### Основные таблицы:
User - пользователи системы

Recipe - рецепты

Comment - комментарии к рецептам

Rating - оценки рецептов

Preference - кулинарные предпочтения

UserPreference - связь пользователей с предпочтениями

UserFavoriteRecipes - избранные рецепты

ImageRecipe - изображения рецептов

## Доступ к функциям
### Для обычных пользователей:
Просмотр рецептов

Регистрация и вход в систему

Создание и редактирование собственных рецептов

Добавление рецептов в избранное

Комментирование и оценка рецептов

### Для администраторов:
Все функции обычных пользователей

Управление пользователями (права администратора)

Управление категориями рецептов

## Особенности интерфейса
Адаптивный дизайн для различных устройств

Интуитивная навигация с навигационной панелью

Визуальное представление рецептов с изображениями

Интерактивные формы с валидацией

Карусель изображений для рецептов с несколькими фото

## Конфигурация
Основные настройки приложения:

Путь для загрузки файлов: /uploads/

Размер загружаемых файлов: до 50MB

Кодировка: UTF-8

Сессия пользователя: с таймаутом

Приложение включает:

Валидацию форм на стороне клиента и сервера

Обработку ошибок с пользовательскими сообщениями

Проверку прав доступа к защищенным ресурсам
